## Limitations
- **Rights:** All findings are provided as `reference_only`. No audio was downloaded, as public availability does not constitute a reuse license. The original platforms (Apple Podcasts) serve as the host.
- **Search Restrictions:** Automated web searching (e.g. DuckDuckGo html scraping) was frequently blocked by captcha/anti-bot systems. Using direct API queries (iTunes Search API) was necessary to overcome this.
- **Human Review Needed:** While confident in the identity of the Daniel Cerezo featured in these podcasts, they have not been manually listened to in full, so all detailed themes are derived from published descriptions.
